# Handover S2

From: P2  
To: P3  
Feature: Ingestion Core

## What was built

- Persistent root consent through the frozen `GET/POST/DELETE /api/roots` API.
- Root revocation that removes only locations and indexed data no longer
  referenced by another approved root.
- Read-only `os.scandir()` traversal with hidden/runtime, video, executable,
  incomplete-download, unsupported-format, exclusion-glob, and 50 MB filters.
- Path/size/mtime prefilter followed by streaming SHA-256 when required.
- Content-hash document identity and duplicate-path handling.
- Page-aware PyMuPDF extraction with no OCR.
- Approximately 500-token chunks with 60-token overlap, page number, ordinal,
  and source position.
- Embedding through `llm.embed`, processed in batches of 32.
- Transactional chunk, FTS5, and existing `chunks_vec` writes.
- Persisted index state with real document/chunk counts and pause/resume.
- Folder indexing CLI and deterministic synthetic corpus generator.

## Contracts used

S1 API models are unchanged. S2 uses the existing `index_roots`, `documents`,
`file_locations`, `chunks`, `chunks_fts`, and `chunks_vec` contracts. It adds
nullable `size_bytes`/`mtime_ns` location metadata and a singleton
`index_state` table. Existing databases are migrated idempotently by
`db.init_db.init_db()`.

## Run

```bash
pip install -r requirements.txt
python scripts/generate_demo_corpus.py
python scripts/index_folder.py demo-data/synthetic
```

Expected output is JSON with nonzero `found`, `unique`, `processed`, and
`chunks`; one duplicate; six skipped non-PDF files; and `"vectors": true`
when `sqlite-vec` is installed.

## Known limitations

- S2 extracts PDF text only. DOCX and screenshot files are included in the
  demo corpus for later sessions but intentionally skipped; OCR is out of scope.
- Vector persistence requires the declared `sqlite-vec` dependency. FTS5 and
  all other ingestion remain usable if that optional extension cannot load.
- This is explicit scan/CLI ingestion; a filesystem watcher is not included.

## P3 input

Start from `handover-S2`. P3 can consume `documents`, `file_locations`,
page-aware `chunks`, `chunks_fts`, and `chunks_vec` directly. Retrieval should
not require changes to the S2 storage contract.
